## 🚀 Featured Projects

### 🔬 [SE-Attention Half U-Net — Medical Image Segmentation](https://github.com/vedanshrathi/SE-Attention-Half-UNet)
> **PyTorch · Attention Gates · Squeeze-and-Excitation Blocks · AMP Training**

A custom lightweight segmentation architecture combining Half U-Net, Attention U-Net, and SE-Net principles. Designed for polyp segmentation on the Kvasir-SEG dataset, achieving a Dice score of **0.90–0.94** and pixel accuracy of **95–97%** — matching larger U-Net architectures at significantly fewer parameters.

- Encoder-heavy / decoder-shallow design for GPU efficiency
- Channel recalibration via SE blocks; noise suppression via Attention Gates
- Custom BCE + Dice hybrid loss with Cosine Annealing Warm Restarts and AMP

---

### 🎮 [Clash of Clans AI Strategy Recommendation System](https://github.com/vedanshrathi)
> **React · FastAPI · SQLite · Tabular Q-Learning · CoC Developer API**

A full-stack AI application that fetches live player data from the official Clash of Clans Developer API and uses **Tabular Q-Learning with four domain-specific heuristics** to recommend optimal attack strategies. Includes a seminar-grade IEEE research paper and system architecture documentation.

- Real-time player data integration via REST API
- Reinforcement learning agent with state-action reward modeling
- Modular React frontend with FastAPI backend and persistent SQLite storage

### 🛡️ [CCTV Examination Anti-Cheat System](https://github.com/vedanshrathi/cctv-examination-anti-cheat-system)
> **Python · YOLOv8 · MediaPipe · Pose Detection · Zone Auto-Detection**

An intelligent computer vision system for real-time exam invigilation. Uses YOLOv8 for object detection combined with pose estimation to automatically flag suspicious behaviour in designated exam zones.

- Automated zone detection via `zone_autodetector.py`
- Multi-component modular design: detection, pose analysis, alerting utilities
- Configurable zone mapping via `zones.json`

### 🖼️ [Image Captioning System — CNN + LSTM + Attention](https://github.com/vedanshrathi/image-captioning-model)
> **TensorFlow/Keras · ResNet50 · LSTM · Attention · Flask**

An end-to-end image captioning pipeline with a web interface. Visual features are extracted by ResNet50, attention focuses on salient regions, and an LSTM decoder generates natural language descriptions. Trained on the Flickr8k dataset and deployed via Flask.

- Full-stack: model training, inference engine, and browser-based UI
- Attention mechanism for region-specific caption generation
- Suitable as a production-level academic AI/ML capstone
